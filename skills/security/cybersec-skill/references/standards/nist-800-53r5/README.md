## Purpose in this skill

800-53 is the **control catalogue** behind CSF 2.0's informative references and FedRAMP, and the most cited control set in the Anthropic-Cybersecurity-Skills playbooks. Use it when a finding or a programme gap needs a formal control (`AC-6 Least Privilege`, `SI-10 Information Input Validation`), when the context is federal or FedRAMP, or to verify crosswalk rows labelled FedRAMP. For application-level verification, ASVS stays the more precise standard.

## Reading and citing rules

- Cite as `AC-2(4) (SP 800-53 Rev. 5.2.0)`. Enhancements are written `CONTROL(n)`.
- `[Assignment: organization-defined …]` and `[Selection: …]` are parameters the organisation must set. A control with unset parameters cannot be PASS: the evidence must show the chosen value.
- Withdrawn controls stay listed with their destination; never cite them as current.
- Baselines (low / moderate / high, privacy) are defined in SP 800-53B, which is not reproduced here (tier B in `../INVENTORY.md`).
