## Purpose in this skill

D3FEND names **countermeasures**. Use it to phrase the defensive side of a finding or a threat model in a standard vocabulary (`D3-MFA Multi-factor Authentication`) and to go from an ATT&CK technique to candidate countermeasures. Like ATT&CK mitigations, a D3FEND technique is a direction of defence, not a compliance criterion: PASS / FAIL rests on the verifiable control (ASVS, SSDF, 800-53, CSF 2.0). Playbooks from Anthropic-Cybersecurity-Skills cite D3FEND techniques **by name**; search this file by label.
