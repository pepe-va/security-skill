## Purpose in this skill

CWE is the **common language of findings**. Every finding carries the CWE of its root cause; from the CWE the skill reaches the OWASP Top 10:2025 category (index below), the ASVS requirements of the matching chapter, and the CAPEC attack patterns the weakness enables. CWE classifies a weakness; it is not a compliance criterion and carries no severity — severity comes from the demonstrated impact and CVSS 4.0.

## Mapping rules (from CWE's own Mapping Notes)

- Prefer the **Base** or **Variant** entry that names the root cause. **Class** and **Pillar** entries are too abstract for a finding unless nothing lower fits.
- Respect each entry's **Usage**: `Allowed` — map freely · `Allowed-with-Review` — map only after checking the description fits · `Discouraged` — find a lower-level entry · `Prohibited` — never map (categories and views are always prohibited).
- Read the name **and** the description before mapping. Do not force a Base/Variant entry that does not fit; a correct Class is better than a wrong Base.
- Cite as `CWE-<id>` with the catalogue version (`CWE 4.20`). Deprecated entries must not be cited.
